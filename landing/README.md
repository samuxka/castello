# Castello ERP & Ponto — Landing Page

Pasta dedicada para os componentes, estilos e recursos da Landing Page de alta conversão do Castello.

## Estrutura de Domínios
- **erpcastle.com** — Landing Page Institucional e de Conversão (Web & Mobile)
- **www.erpcastle.com** — Redirecionamento permanente (301) para `https://erpcastle.com`
- **app.erpcastle.com** — Sistema ERP Web de Gestão de Obras, Equipas, Ponto e Finanças
